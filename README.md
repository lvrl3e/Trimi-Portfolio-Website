# Trimi — Portfolio Website

Personal portfolio for Trimi, a full-stack developer and app maker. Built with React, TypeScript, Tailwind CSS, and Lucide icons.

## Getting started

```bash
npm install
npm run dev
```

## Before deploying

- Replace the placeholder profile image in [Hero.tsx](src/components/Hero.tsx) with a real photo.
- Fill in the real LinkedIn URL and contact email in [Navbar.tsx](src/components/Navbar.tsx), [Contact.tsx](src/components/Contact.tsx), and [Footer.tsx](src/components/Footer.tsx).
- Add real project links (GitHub / live demo) in [src/data/projects.ts](src/data/projects.ts).

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run preview` — preview the production build locally
